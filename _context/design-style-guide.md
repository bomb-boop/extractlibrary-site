# EXTRACT LIBRARY — 디자인 스타일 가이드

## 디자인 컨셉
- "성분을 기록하는 서고(library)"라는 브랜드 컨셉에 맞춰, 감성적인 뷰티 광고보다는 **아카이브/카탈로그/기록 카드**에 가까운 차분하고 절제된 톤앤매너.
- 짙은 리넨/종이(paper) 배경에 진한 잉크색 텍스트, 세리프 헤드라인 + 모노스페이스 라벨의 대비로 "편집/출판물" 느낌을 연출.

## 컬러 팔레트 (웹사이트 기준, `style.css`)
| 변수 | HEX | 용도 |
|---|---|---|
| `--paper` | `#F4F0E6` | 기본 배경 (따뜻한 종이색) |
| `--paper-dim` | `#EBE5D6` | 대비 섹션 배경, 카드 hover |
| `--ink` | `#211E18` | 본문 텍스트 |
| `--ink-soft` | `#4A463C` | 보조 텍스트 |
| `--forest` | `#2F3B2C` | 헤드라인, 브랜드 그린 |
| `--amber` | `#6B4226` | 링크, 강조 텍스트, callnum |
| `--sage` | `#8B9A7B` | 세이지 그린 (보조) |
| `--gold` | `#A9803D` | 강조/포인트 (eyebrow, 로고 dot) |
| `--rule` | `rgba(33,30,24,0.16)` | 구분선 |

- 상세페이지(제품 이미지)에서는 브랜드 블랙(짙은 남색/블랙 계열 병 용기)과 크림/베이지 배경, 병풀의 그린 컬러가 포인트로 사용됨. 웹사이트 톤(--paper 계열 warm beige)과도 자연스럽게 연결됨.

## 타이포그래피
- **Display/제목용 세리프**: `Fraunces` (weight 500–600) — h1, h2, h3, `.display`, 인용구(`.quote`)에 사용. letter-spacing -0.01em로 살짝 타이트하게.
- **본문**: `Work Sans` (400–500) — 기본 body 폰트.
- **라벨/모노**: `IBM Plex Mono` (400–500) — nav, `.callnum`(카탈로그 번호), `.eyebrow`, `.meta`, spec 테이블 th 등 "데이터/기록" 느낌을 주는 곳에 사용.
- 폰트 조합 원칙: 세리프(감성/브랜드) + 모노스페이스(데이터/근거) + 산세리프(가독성) 3종 조합으로 "브랜드 스토리 vs 임상 데이터"의 대비를 시각적으로 표현.

## 레이아웃 패턴
- `.wrap` 컨테이너 max-width 920px, 중앙 정렬, 좌우 padding 28px — 좁고 읽기 편한 컬럼 폭 (에디토리얼 사이트 느낌).
- Header: sticky, 68px 높이, 로고 좌측 + nav 우측 정렬.
- Hero 섹션: `.eyebrow` 라벨(카테고리 태그, gold border) → 세리프 h1 (max 12ch로 줄바꿈 유도) → `.lede` 서브카피(52ch 제한) 순서.
- 제품 스펙은 항상 2열 `table.spec` 형식 (th 30% width, 모노스페이스 라벨 + uppercase) — "기록 카드"처럼 제시.
- 인용구는 `.quote` — 좌측 gold 3px border + 세리프 italic.
- 카탈로그 카드 그리드(`.card-grid`): 1px gap의 그리드 라인으로 구분되는 미니멀 카드, hover 시 paper-dim 배경.
- 섹션 간 구분은 배경색 교차(`section.alt`)와 얇은 rule 보더로 처리, 그림자(box-shadow) 사용 최소화.

## 상세페이지(제품 이미지) 레이아웃 패턴 (Cafe24 상세페이지 기준)
- 세로로 긴 스토리텔링형 상세페이지: 히어로(제품명+캡션) → 4대 기능 아이콘 → Check Point 리스트(형광펜 하이라이트 타이틀) → 감성 카피+자연 이미지 → 페인포인트 공감 문구 → 실사용자 후기(비포/애프터 사진) → 경쟁사 VS 비교 → 성분 상세(카드형 성분 4종 + 전성분 등급표) → 임상시험 결과표 → pH 스펙트럼 그래픽 → 향 설명(감성 카피) → 사용법 3단계(번호+아이콘) → 추천 루틴(STEP 1→2).
- 타이틀 강조 기법: 브랜드 로고 상단 배지, 노란 형광펜 밑줄/배경으로 핵심 카피 강조("CHECK POINT" 등), 체크박스 아이콘 리스트.
- 비포/애프터는 항상 동일 인물의 좌/우 대비 사진 + 초록색 화살표(→) 아이콘.
- 성분 카드: 아이콘 원형 배경(그린/뉴트럴 톤) + 성분명 + 1줄 효능 설명, 4개 그리드.
- 데이터 시각화: pH 스펙트럼(1~10 스케일 원형 마커), 성분 등급표(초록/노랑 뱃지).
- 인물 사진 톤: 화이트/크림 배경, 자연광, 톤다운된 스킨톤 보정 — 과도한 보정 지양.
- 자연물 이미지(병풀잎, 물방울, 숲)는 향과 성분의 "자연 유래" 스토리를 시각적으로 뒷받침하는 무드컷으로 사용.
- 제품별 반복 패턴: 두 제품(병풀 클렌징 워터/어성초 진정 토너) 상세페이지는 동일한 섹션 순서·컴포넌트를 재사용하며 성분·컬러 포인트만 교체됨 — 신제품 출시 시 이 템플릿을 그대로 따를 것.
  - 인물 컷은 라이프스타일 포트레이트(슬립 드레스, 자연스러운 업스타일 헤어, 손으로 얼굴 터치)와 클로즈업 제품 컷을 번갈아 배치.
  - 해시태그 라인(`#키워드 #키워드 #키워드`)으로 핵심 효능을 압축 요약하는 섹션이 헤더 카피 아래 위치.
  - 핵심 성분 시너지는 번호형 카드(01~04)로 제시 — 각 카드는 "성분 조합" 헤드라인 + 1줄 근거 설명 구조.
  - 브랜드 로고(EXTRACT LIBRARY)를 인물/무드컷 이미지 위에 워터마크처럼 얇게 오버레이해 배치.

## 적용 원칙
- 새 상세페이지/배너 제작 시: 위 웹사이트 색상 팔레트(브랜드 official) 와 Cafe24 상세페이지의 크림/블랙 톤을 혼동하지 말고, 각 채널의 기존 톤을 유지하되 세리프+모노스페이스 타이포 대비, "기록/데이터" 프레이밍은 채널 불문 일관되게 적용할 것.
